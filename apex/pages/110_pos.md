# صفحة 110 - شاشة الكاشير (JSON) + 111 إغلاق الوردية + 112 الإيصال + 113 تقارير المبيعات

لكل شركة نقاط بيع منفصلة، ولكل نقطة مخزن وصندوق. كل شركة تبيع بقائمة أسعارها (`companies.pos_price_list_id`).

**دورة العمل:**
1. **فتح وردية** برصيد افتتاحي. يُسمح بوردية مفتوحة واحدة لكل نقطة بيع.
2. **البيع:** كل فاتورة تُخصم من المخزن فوراً، بحركة `POS` مرحّلة بمتوسط التكلفة.
3. **الدفع:** نقداً أو بطاقة، وبأكثر من عملة. الباقي يُعاد بالعملة الأساسية.
4. **إغلاق الوردية:** عدّ النقد، ثم يُنشأ **قيد واحد للوردية**:

| مدين | دائن |
|---|---|
| صندوق نقطة البيع (النقد الصافي) | مبيعات نقاط البيع `POS_SALES` (صافي المبيعات − المرتجعات) |
| حساب البطاقات (مدفوعات البطاقة) | |
| تكلفة البضاعة `COGS` | المخزون `INVENTORY` |
| عجز الصندوق `CASH_DIFF` (إن وُجد) | أو زيادة الصندوق `CASH_DIFF` |

## Region A: فتح وردية (Condition: `P110_SHIFT_ID` Is Null)

`P110_OPENING_CASH` + زر **فتح وردية** (Request `OPEN_SHIFT`).

**Process `OPEN_SHIFT`:**
```sql
DECLARE l_cnt NUMBER;
BEGIN
  SELECT COUNT(*) INTO l_cnt FROM pos_terminal_users
  WHERE terminal_id = :P110_TERMINAL_ID AND user_name = UPPER(:APP_USER);
  IF l_cnt = 0 THEN raise_application_error(-20040, 'غير مصرح لك بهذه النقطة'); END IF;
```

```sql
DECLARE
  l_items CLOB; l_cur CLOB;
  l_term  pos_terminals%ROWTYPE;
  l_pl    NUMBER;
BEGIN
  SELECT * INTO l_term FROM pos_terminals WHERE terminal_id = TO_NUMBER(apex_application.g_x01);
  SELECT pos_price_list_id INTO l_pl FROM companies WHERE company_id = l_term.company_id;

  -- الباركودات أولاً ثم أكواد الأصناف (حتى يُعرض كود الصنف عند إعادة الرسم)
  SELECT JSON_ARRAYAGG(o RETURNING CLOB) INTO l_items FROM (
    SELECT JSON_OBJECT('id' VALUE u.item_id, 'code' VALUE u.barcode, 'name' VALUE i.name_ar,
                       'unit' VALUE u.unit_id) o, 1 grp, u.barcode k
    FROM item_units u JOIN items i ON i.item_id = u.item_id
    WHERE u.barcode IS NOT NULL AND i.is_active = 'Y'
    UNION ALL
    SELECT JSON_OBJECT('id' VALUE i.item_id, 'code' VALUE i.item_code, 'name' VALUE i.name_ar,
             'bal' VALUE NVL(b.qty_base, 0),
             'units' VALUE (SELECT JSON_ARRAYAGG(JSON_OBJECT('v' VALUE u.unit_id, 't' VALUE un.name_ar,
                                   'factor' VALUE u.factor, 'price' VALUE p.price) ORDER BY u.factor)
                            FROM item_units u JOIN units un ON un.unit_id = u.unit_id
                            JOIN price_list_items p ON p.price_list_id = l_pl
                                 AND p.item_id = u.item_id AND p.unit_id = u.unit_id
                            WHERE u.item_id = i.item_id) FORMAT JSON), 2, i.item_code
    FROM items i
    LEFT JOIN v_stock_balance b ON b.item_id = i.item_id AND b.warehouse_id = l_term.warehouse_id
    WHERE i.is_active = 'Y'
    AND EXISTS (SELECT 1 FROM price_list_items p WHERE p.price_list_id = l_pl AND p.item_id = i.item_id)
    ORDER BY 2, 3);

  SELECT JSON_ARRAYAGG(JSON_OBJECT('v' VALUE c.currency_code, 't' VALUE c.currency_code,
                                   'rate' VALUE r.rate) ORDER BY c.is_base DESC RETURNING CLOB)
  INTO l_cur
  FROM currencies c JOIN v_latest_rates r ON r.currency_code = c.currency_code
  WHERE c.is_active = 'Y';

  apex_util.prn('{"items":' || COALESCE(l_items, TO_CLOB('[]')) ||
                ',"currencies":' || COALESCE(l_cur, TO_CLOB('[]')) || '}', FALSE);
END;
```

## Ajax Callback: `SAVE_SALE`

```sql
DECLARE
  l_clob    CLOB := apex_application.g_clob_01;
  l_errs    apex_t_varchar2 := apex_t_varchar2();
  l_shift   pos_shifts%ROWTYPE;
  l_term    pos_terminals%ROWTYPE;
  l_pl      NUMBER;
  l_type    VARCHAR2(10);
  l_cust    VARCHAR2(150);
  l_disc    NUMBER;
  l_sign    NUMBER;
  l_gross   NUMBER := 0;
  l_net     NUMBER;
  l_paid    NUMBER := 0;
  l_cash    NUMBER := 0;
  l_change  NUMBER;
  l_id      NUMBER;
  l_no      VARCHAR2(30);
  l_seq     NUMBER;
  l_st      NUMBER;
  l_cnt     NUMBER;

  PROCEDURE err (p VARCHAR2) IS BEGIN l_errs.EXTEND; l_errs(l_errs.COUNT) := p; END;
BEGIN
  SELECT * INTO l_shift FROM pos_shifts
  WHERE shift_id = JSON_VALUE(l_clob, '$.header.SHIFT_ID' RETURNING NUMBER) FOR UPDATE;
  IF l_shift.status <> 'OPEN' OR l_shift.user_name <> UPPER(:APP_USER) THEN
    raise_application_error(-20042, 'الوردية مغلقة أو ليست لك');
  END IF;
  SELECT * INTO l_term FROM pos_terminals WHERE terminal_id = l_shift.terminal_id;
  SELECT pos_price_list_id INTO l_pl FROM companies WHERE company_id = l_term.company_id;

  l_type := CASE JSON_VALUE(l_clob, '$.header.IS_RETURN') WHEN 'Y' THEN 'RETURN' ELSE 'SALE' END;
  l_sign := CASE l_type WHEN 'SALE' THEN -1 ELSE 1 END;          -- أثر الكمية على المخزن
  l_cust := JSON_VALUE(l_clob, '$.header.CUSTOMER');
  l_disc := NVL(JSON_VALUE(l_clob, '$.header.DISCOUNT' RETURNING NUMBER), 0);

  -- السعر يؤخذ من قائمة الأسعار في الخادم دائماً
  FOR r IN (SELECT j.line_no, j.item_id, j.unit_id, j.qty, NVL(j.discount, 0) discount, p.price, u.factor,
                   i.item_code, NVL(b.qty_base, 0) bal
            FROM JSON_TABLE(l_clob, '$.lines[*]' COLUMNS (
                   line_no NUMBER PATH '$.LINE_NO', item_id NUMBER PATH '$.ITEM_ID',
                   unit_id NUMBER PATH '$.UNIT_ID', qty NUMBER PATH '$.QTY', discount NUMBER PATH '$.DISCOUNT')) j
            LEFT JOIN item_units u ON u.item_id = j.item_id AND u.unit_id = j.unit_id
            LEFT JOIN items i ON i.item_id = j.item_id
            LEFT JOIN price_list_items p ON p.price_list_id = l_pl AND p.item_id = j.item_id AND p.unit_id = j.unit_id
            LEFT JOIN v_stock_balance b ON b.item_id = j.item_id AND b.warehouse_id = l_term.warehouse_id) LOOP
    IF r.price IS NULL THEN err('السطر ' || r.line_no || ': لا يوجد سعر لهذا الصنف/الوحدة'); END IF;
    IF NVL(r.qty, 0) <= 0 THEN err('السطر ' || r.line_no || ': الكمية غير صحيحة'); END IF;
    IF l_type = 'SALE' AND r.qty * r.factor > r.bal THEN
      err(r.item_code || ': الرصيد المتاح ' || r.bal);
    END IF;
    l_gross := l_gross + NVL(r.qty * r.price, 0) - r.discount;
  END LOOP;
  l_net := l_gross - l_disc;
  IF l_net <= 0 THEN err('صافي الفاتورة غير صحيح'); END IF;

  -- المدفوعات بسعر صرف اليوم
  FOR p IN (SELECT j.pay_method, j.currency_code, j.amount, r.rate
            FROM JSON_TABLE(l_clob, '$.payments[*]' COLUMNS (
                   pay_method VARCHAR2(10) PATH '$.PAY_METHOD', currency_code VARCHAR2(3) PATH '$.CURRENCY_CODE',
                   amount NUMBER PATH '$.AMOUNT')) j
            LEFT JOIN v_latest_rates r ON r.currency_code = j.currency_code) LOOP
    IF p.rate IS NULL OR NVL(p.amount, 0) <= 0 THEN err('سطر دفع غير صحيح'); END IF;
    IF p.pay_method = 'CARD' AND l_term.card_account_id IS NULL THEN err('نقطة البيع لا تقبل البطاقات'); END IF;
    l_paid := l_paid + ROUND(NVL(p.amount, 0) * NVL(p.rate, 0), 2);
    IF p.pay_method = 'CASH' THEN l_cash := l_cash + ROUND(NVL(p.amount, 0) * NVL(p.rate, 0), 2); END IF;
  END LOOP;
  IF l_type = 'SALE' AND l_paid < l_net THEN err('المدفوع أقل من صافي الفاتورة'); END IF;
  l_change := CASE WHEN l_type = 'SALE' THEN l_paid - l_net ELSE 0 END;
  IF l_change > l_cash THEN err('الباقي أكبر من المدفوع نقداً. البطاقة لا يُرد منها باقٍ'); END IF;

  IF l_errs.COUNT > 0 THEN
    ROLLBACK;
    apex_json.open_object; apex_json.write('ok', FALSE); apex_json.write('errors', l_errs); apex_json.close_object;
    RETURN;
  END IF;

  -- الرقم
  UPDATE doc_sequences SET last_no = last_no + 1
  WHERE company_id = l_term.company_id AND doc_type = 'POS' AND fy_year = EXTRACT(YEAR FROM SYSDATE)
  RETURNING last_no INTO l_seq;
  IF SQL%ROWCOUNT = 0 THEN
    INSERT INTO doc_sequences VALUES (l_term.company_id, 'POS', EXTRACT(YEAR FROM SYSDATE), 1); l_seq := 1;
  END IF;
  l_no := 'POS-' || EXTRACT(YEAR FROM SYSDATE) || '-' || LPAD(l_seq, 6, '0');

  INSERT INTO pos_sales (shift_id, company_id, sale_no, sale_type, customer_name, gross_amount,
                         discount_amount, net_amount, paid_base, change_base, created_by)
  VALUES (l_shift.shift_id, l_term.company_id, l_no, l_type, l_cust, l_gross, l_disc, l_net,
          CASE WHEN l_type = 'SALE' THEN l_paid ELSE l_net END, l_change, :APP_USER)
  RETURNING sale_id INTO l_id;

  INSERT INTO pos_sale_lines (sale_id, line_no, item_id, unit_id, factor, qty, price, discount, line_total)
  SELECT l_id, ROWNUM, j.item_id, j.unit_id, u.factor, j.qty, p.price, NVL(j.discount, 0),
         j.qty * p.price - NVL(j.discount, 0)
  FROM JSON_TABLE(l_clob, '$.lines[*]' COLUMNS (
         item_id NUMBER PATH '$.ITEM_ID', unit_id NUMBER PATH '$.UNIT_ID',
         qty NUMBER PATH '$.QTY', discount NUMBER PATH '$.DISCOUNT')) j
  JOIN item_units u ON u.item_id = j.item_id AND u.unit_id = j.unit_id
  JOIN price_list_items p ON p.price_list_id = l_pl AND p.item_id = j.item_id AND p.unit_id = j.unit_id;

  IF l_type = 'SALE' THEN
    INSERT INTO pos_payments (sale_id, pay_method, currency_code, exchange_rate, amount, amount_base)
    SELECT l_id, j.pay_method, j.currency_code, r.rate, j.amount, ROUND(j.amount * r.rate, 2)
    FROM JSON_TABLE(l_clob, '$.payments[*]' COLUMNS (
           pay_method VARCHAR2(10) PATH '$.PAY_METHOD', currency_code VARCHAR2(3) PATH '$.CURRENCY_CODE',
           amount NUMBER PATH '$.AMOUNT')) j
    JOIN v_latest_rates r ON r.currency_code = j.currency_code;
  ELSE
    -- المرتجع يُرد نقداً بالعملة الأساسية
    INSERT INTO pos_payments (sale_id, pay_method, currency_code, exchange_rate, amount, amount_base)
    SELECT l_id, 'CASH', currency_code, 1, l_net, l_net FROM currencies WHERE is_base = 'Y';
  END IF;

  -- حركة المخزون الفورية بمتوسط التكلفة
  INSERT INTO stock_trans (company_id, trans_type, trans_no, trans_date, warehouse_id, currency_code,
                           exchange_rate, description, source_type, source_id, status, created_by)
  VALUES (l_term.company_id, 'POS', l_no, TRUNC(SYSDATE), l_term.warehouse_id,
          (SELECT currency_code FROM currencies WHERE is_base = 'Y'), 1,
          l_no, 'POS', l_id, 'POSTED', :APP_USER)
  RETURNING trans_id INTO l_st;

  INSERT INTO stock_trans_lines (trans_id, line_no, warehouse_id, item_id, unit_id, factor, qty,
                                 qty_base, unit_cost, cost_base, value_base)
  SELECT l_st, l.line_no, l_term.warehouse_id, l.item_id, l.unit_id, l.factor, l.qty,
         l_sign * l.qty * l.factor, 0, NVL(b.avg_cost, 0),
         ROUND(l_sign * l.qty * l.factor * NVL(b.avg_cost, 0), 4)
  FROM pos_sale_lines l
  LEFT JOIN v_stock_balance b ON b.item_id = l.item_id AND b.warehouse_id = l_term.warehouse_id
  WHERE l.sale_id = l_id;

  apex_json.open_object;
  apex_json.write('ok', TRUE); apex_json.write('id', l_id); apex_json.write('no', l_no);
  apex_json.write('change', l_change);
  apex_json.write('message', 'تم حفظ ' || l_no || CASE WHEN l_change > 0 THEN ' - الباقي: ' || TO_CHAR(l_change, 'FM999G999G990D00') END);
  apex_json.close_object;
EXCEPTION WHEN OTHERS THEN
  ROLLBACK;
  apex_json.open_object; apex_json.write('ok', FALSE);
  apex_json.open_array('errors'); apex_json.write(SQLERRM); apex_json.close_array;
  apex_json.close_object;
END;
```

## JavaScript: Function and Global Variable Declaration

```javascript
var pos = {
  grid: null, pay: null, currencies: [], barcodes: {},

  unitsOf: function (row, g) { var it = (g || pos.grid).lovRecord('items', row.ITEM_ID); return (it && it.units) || []; },

  init: function () {
    if (!apex.item('P110_SHIFT_ID').getValue()) return;

    pos.grid = new JsonLines({
      container: '#pos_lines',
      columns: [
        {name: 'ITEM_ID',  label: 'الصنف / الباركود', type: 'lov', lov: 'items', required: true, width: '24em'},
        {name: 'UNIT_ID',  label: 'الوحدة', type: 'select', nullText: false, options: pos.unitsOf, width: '8em'},
        {name: 'QTY',      label: 'الكمية', type: 'number', decimals: 2, required: true, width: '6em'},
        {name: 'PRICE',    label: 'السعر', type: 'number', decimals: 2, readonly: true, noSubmit: true, width: '8em'},
        {name: 'DISCOUNT', label: 'الخصم', type: 'number', decimals: 2, width: '6em'},
        {name: 'TOTAL',    label: 'الإجمالي', type: 'display', decimals: 2, total: true, noSubmit: true}
      ],
      onChange: function (row, col) {
        if (col === 'ITEM_ID') {
          var bc = pos.barcodes[String(row['ITEM_ID$text'] || '').toUpperCase()];
          var u = pos.unitsOf(row);
          row.UNIT_ID = bc ? bc : (u.length ? u[0].v : null);    // وحدة الباركود أو أصغر وحدة
          if (!row.QTY) row.QTY = 1;
        }
        var unit = pos.unitsOf(row).filter(function (x) { return String(x.v) === String(row.UNIT_ID); })[0];
        row.PRICE = unit ? unit.price : null;
        row.TOTAL = (row.QTY || 0) * (row.PRICE || 0) - (row.DISCOUNT || 0);
      },
      onTotals: pos.totals
    });

    pos.pay = new JsonLines({
      container: '#pos_pay',
      columns: [
        {name: 'PAY_METHOD', label: 'الطريقة', type: 'select', nullText: false, defaultValue: 'CASH', width: '8em',
         options: [{v: 'CASH', t: 'نقد'}, {v: 'CARD', t: 'بطاقة'}]},
        {name: 'CURRENCY_CODE', label: 'العملة', type: 'select', nullText: false, width: '7em', ignoreEmpty: true,
         options: function () { return pos.currencies; }},
        {name: 'AMOUNT', label: 'المبلغ', type: 'number', decimals: 2, required: true, width: '10em'},
        {name: 'RATE',   label: 'السعر', type: 'display', decimals: 4, noSubmit: true},
        {name: 'BASE',   label: 'بالعملة الأساسية', type: 'display', decimals: 2, total: true, noSubmit: true}
      ],
      newRow: function (r) { r.CURRENCY_CODE = pos.currencies.length ? pos.currencies[0].v : null; },
      onChange: function (row) {
        var c = pos.currencies.filter(function (x) { return x.v === row.CURRENCY_CODE; })[0];
        row.RATE = c ? c.rate : null;
        row.BASE = (row.AMOUNT || 0) * (row.RATE || 0);
      },
      onTotals: pos.totals
    });

    apex.server.process('INIT_DATA', {x01: apex.item('P110_TERMINAL_ID').getValue()}, {dataType: 'json'})
      .done(function (d) {
        d.items.forEach(function (x) { if (x.unit) pos.barcodes[String(x.code).toUpperCase()] = x.unit; });
        pos.currencies = d.currencies;
        pos.grid.setLov('items', d.items);
        pos.pay.setData([]);
        pos.grid.focusRow(0);
      });

    apex.jQuery('#P110_DISCOUNT').on('change', pos.totals);
    document.addEventListener('keydown', function (e) {
      if (e.key === 'F9') { e.preventDefault(); pos.save(); }
      if (e.key === 'F4') { e.preventDefault(); pos.reset(); }
      if (e.key === 'F8') { e.preventDefault(); pos.pay.focusRow(pos.pay.rows.length - 1); }
    });
  },

  totals: function () {
    if (!pos.grid || !pos.pay) return;
    var net  = (pos.grid.totals().TOTAL || 0) - (JsonLines.toNum(apex.item('P110_DISCOUNT').getValue()) || 0),
        paid = pos.pay.totals().BASE || 0;
    document.getElementById('pos_net').textContent    = JsonLines.fmt(net, 2);
    document.getElementById('pos_paid').textContent   = JsonLines.fmt(paid, 2);
    document.getElementById('pos_change').textContent = JsonLines.fmt(Math.max(paid - net, 0), 2);
  },

  reset: function () {
    pos.grid.setData([]); pos.pay.setData([]);
    apex.item('P110_DISCOUNT').setValue(''); apex.item('P110_CUSTOMER').setValue('');
    apex.item('P110_IS_RETURN').setValue('N');
    pos.totals(); pos.grid.focusRow(0);
  },

  save: function () {
    var isRet = apex.item('P110_IS_RETURN').getValue() === 'Y';
    var errs = pos.grid.validate();
    if (!isRet) errs = errs.concat(pos.pay.validate());
    if (errs.length) { DocUtil.showErrors(errs); return; }
    var doc = {
      header: {SHIFT_ID: apex.item('P110_SHIFT_ID').getValue(), IS_RETURN: isRet ? 'Y' : 'N',
               CUSTOMER: apex.item('P110_CUSTOMER').getValue(),
               DISCOUNT: JsonLines.toNum(apex.item('P110_DISCOUNT').getValue())},
      lines: pos.grid.getData(),
      payments: isRet ? [] : pos.pay.getData()
    };
    DocUtil.save(doc, 'POST', function (d) {
      window.open(apex.util.makeApplicationUrl({pageId: 112, itemNames: ['P112_SALE_ID'], itemValues: [d.id]}),
                  'receipt', 'width=380,height=600');
      pos.reset();
    }, 'SAVE_SALE');
  }
};
```

## صفحة 111 - إغلاق الوردية

**Items:** `P111_SHIFT_ID` (من صفحة 110)، `P111_COUNTED_CASH` (Number، Required)، `P111_EXPECTED` (Display Only).

**Computation لـ `P111_EXPECTED`** (النقد المتوقع في الصندوق بالعملة الأساسية):
```sql
SELECT s.opening_cash
     + NVL((SELECT SUM(CASE WHEN ps.sale_type = 'SALE' THEN p.amount_base ELSE -p.amount_base END)
            FROM pos_sales ps JOIN pos_payments p ON p.sale_id = ps.sale_id
            WHERE ps.shift_id = s.shift_id AND p.pay_method = 'CASH'), 0)
     - NVL((SELECT SUM(change_base) FROM pos_sales WHERE shift_id = s.shift_id), 0)
FROM pos_shifts s WHERE s.shift_id = :P111_SHIFT_ID
```

**Region: ملخص الوردية (Classic Report):**
```sql
SELECT DECODE(ps.sale_type,'SALE','مبيعات','مرتجعات') "النوع", COUNT(*) "العدد",
       SUM(ps.net_amount) "الصافي",
       SUM((SELECT NVL(SUM(amount_base),0) FROM pos_payments p WHERE p.sale_id = ps.sale_id AND p.pay_method='CASH')) "نقداً",
       SUM((SELECT NVL(SUM(amount_base),0) FROM pos_payments p WHERE p.sale_id = ps.sale_id AND p.pay_method='CARD')) "بطاقة"
FROM pos_sales ps WHERE ps.shift_id = :P111_SHIFT_ID
GROUP BY ps.sale_type
```

**Process `CLOSE_SHIFT` (زر "إغلاق الوردية وترحيل القيد"):**

```sql
DECLARE
  s        pos_shifts%ROWTYPE;
  t        pos_terminals%ROWTYPE;
  l_base   VARCHAR2(3);
  l_jid    NUMBER;
  l_line   NUMBER := 0;
  l_seq    NUMBER;
  l_sales  NUMBER;  l_cash NUMBER;  l_card NUMBER;  l_cogs NUMBER;  l_diff NUMBER;
  l_acc_sales NUMBER; l_acc_cogs NUMBER; l_acc_inv NUMBER; l_acc_diff NUMBER;

  FUNCTION setting (p_code VARCHAR2) RETURN NUMBER IS l NUMBER;
  BEGIN
    SELECT account_id INTO l FROM account_settings WHERE company_id = t.company_id AND setting_code = p_code;
    RETURN l;
  EXCEPTION WHEN NO_DATA_FOUND THEN raise_application_error(-20050, 'لم يُعرَّف الحساب ' || p_code);
  END;

  PROCEDURE jline (p_acc NUMBER, p_amt NUMBER, p_desc VARCHAR2) IS
  BEGIN
    IF ROUND(NVL(p_amt, 0), 2) = 0 THEN RETURN; END IF;
    l_line := l_line + 1;
    INSERT INTO journal_lines (journal_id, line_no, account_id, debit, credit, debit_base, credit_base, description)
    VALUES (l_jid, l_line, p_acc, GREATEST(ROUND(p_amt,2),0), GREATEST(-ROUND(p_amt,2),0),
            GREATEST(ROUND(p_amt,2),0), GREATEST(-ROUND(p_amt,2),0), p_desc);
  END;
BEGIN
  SELECT * INTO s FROM pos_shifts WHERE shift_id = :P111_SHIFT_ID FOR UPDATE;
  IF s.status <> 'OPEN' THEN raise_application_error(-20051, 'الوردية مغلقة'); END IF;
  IF s.user_name <> UPPER(:APP_USER) AND :G_USER_ROLE <> 'GM' THEN
    raise_application_error(-20052, 'لا يمكنك إغلاق وردية مستخدم آخر');
  END IF;
  SELECT * INTO t FROM pos_terminals WHERE terminal_id = s.terminal_id;
  SELECT currency_code INTO l_base FROM currencies WHERE is_base = 'Y';

  SELECT NVL(SUM(CASE sale_type WHEN 'SALE' THEN net_amount ELSE -net_amount END), 0)
  INTO   l_sales FROM pos_sales WHERE shift_id = s.shift_id;

  SELECT NVL(SUM(CASE WHEN ps.sale_type = 'SALE' THEN p.amount_base ELSE -p.amount_base END), 0)
  INTO   l_cash
  FROM   pos_sales ps JOIN pos_payments p ON p.sale_id = ps.sale_id
  WHERE  ps.shift_id = s.shift_id AND p.pay_method = 'CASH';

  SELECT l_cash - NVL(SUM(change_base), 0) INTO l_cash FROM pos_sales WHERE shift_id = s.shift_id;

  SELECT NVL(SUM(p.amount_base), 0) INTO l_card
  FROM   pos_sales ps JOIN pos_payments p ON p.sale_id = ps.sale_id
  WHERE  ps.shift_id = s.shift_id AND p.pay_method = 'CARD';

  SELECT NVL(-SUM(l.value_base), 0) INTO l_cogs
  FROM   stock_trans st JOIN stock_trans_lines l ON l.trans_id = st.trans_id
  WHERE  st.source_type = 'POS' AND st.status = 'POSTED'
  AND    st.source_id IN (SELECT sale_id FROM pos_sales WHERE shift_id = s.shift_id);

  -- الفرق بين المعدود والمتوقع (الرصيد الافتتاحي ليس جزءاً من مبيعات الوردية)
  l_diff := NVL(:P111_COUNTED_CASH, 0) - (s.opening_cash + l_cash);

  l_acc_sales := setting('POS_SALES');  l_acc_cogs := setting('COGS');
  l_acc_inv   := setting('INVENTORY');  l_acc_diff := setting('CASH_DIFF');

  IF l_sales <> 0 OR l_cogs <> 0 OR l_diff <> 0 THEN
    UPDATE doc_sequences SET last_no = last_no + 1
    WHERE company_id = t.company_id AND doc_type = 'JV' AND fy_year = EXTRACT(YEAR FROM SYSDATE)
    RETURNING last_no INTO l_seq;
    IF SQL%ROWCOUNT = 0 THEN
      INSERT INTO doc_sequences VALUES (t.company_id, 'JV', EXTRACT(YEAR FROM SYSDATE), 1); l_seq := 1;
    END IF;

    INSERT INTO journals (company_id, jt_code, journal_no, journal_date, currency_code, exchange_rate,
                          description, status, source_type, source_id, created_by, posted_by, posted_on)
    VALUES (t.company_id, 'JV', 'JV-' || EXTRACT(YEAR FROM SYSDATE) || '-' || LPAD(l_seq, 5, '0'),
            TRUNC(SYSDATE), l_base, 1, 'إغلاق وردية ' || s.shift_id || ' - ' || t.name_ar,
            'POSTED', 'MANUAL', s.shift_id, :APP_USER, :APP_USER, SYSDATE)
    RETURNING journal_id INTO l_jid;

    jline(t.cash_account_id, l_cash + l_diff, 'نقدية الوردية');
    jline(t.card_account_id, l_card,          'مدفوعات البطاقات');
    jline(l_acc_sales,       -l_sales,        'مبيعات الوردية');
    jline(l_acc_diff,        -l_diff,         CASE WHEN l_diff < 0 THEN 'عجز صندوق' ELSE 'زيادة صندوق' END);
    jline(l_acc_cogs,        l_cogs,          'تكلفة المبيعات');
    jline(l_acc_inv,         -l_cogs,         'تكلفة المبيعات');

    UPDATE journals SET total_debit  = (SELECT SUM(debit)  FROM journal_lines WHERE journal_id = l_jid),
                        total_credit = (SELECT SUM(credit) FROM journal_lines WHERE journal_id = l_jid)
    WHERE journal_id = l_jid;
  END IF;

  UPDATE pos_shifts SET status = 'CLOSED', closed_on = SYSDATE, counted_cash = :P111_COUNTED_CASH,
                        expected_cash = s.opening_cash + l_cash, journal_id = l_jid
  WHERE shift_id = s.shift_id;

  apex_application.g_print_success_message := 'تم إغلاق الوردية'
     || CASE WHEN l_diff <> 0 THEN ' - الفرق: ' || TO_CHAR(l_diff, 'FM999G999G990D00') END;
END;
```

> قيد الوردية يُسجَّل بنوع `JV`. لتمييزه أضف نوع قيد `POS` في شاشة أنواع القيود (manual_allowed = N)، واستبدل `'JV'` بـ `'POS'` في السطرين.

## صفحة 113 - تقارير نقاط البيع

**المبيعات اليومية لكل شركة ونقطة بيع:**

```sql
SELECT c.name_ar "الشركة", t.name_ar "نقطة البيع", TRUNC(s.sale_date) "اليوم",
       SUM(CASE s.sale_type WHEN 'SALE' THEN s.net_amount END) "المبيعات",
       SUM(CASE s.sale_type WHEN 'RETURN' THEN s.net_amount END) "المرتجعات",
       SUM(CASE s.sale_type WHEN 'SALE' THEN s.net_amount ELSE -s.net_amount END) "الصافي",
       COUNT(CASE s.sale_type WHEN 'SALE' THEN 1 END) "عدد الفواتير"
FROM pos_sales s
JOIN pos_shifts sh ON sh.shift_id = s.shift_id
JOIN pos_terminals t ON t.terminal_id = sh.terminal_id
JOIN companies c ON c.company_id = s.company_id
WHERE (:G_USER_ROLE = 'GM' OR s.company_id = :G_COMPANY_ID)
AND   s.sale_date >= TO_DATE(:P113_FROM, 'DD/MM/YYYY') AND s.sale_date < TO_DATE(:P113_TO, 'DD/MM/YYYY') + 1
GROUP BY c.name_ar, t.name_ar, TRUNC(s.sale_date)
ORDER BY 3 DESC, 1, 2
```

**أكثر الأصناف مبيعاً مع الربح:**

```sql
SELECT i.item_code "الكود", i.name_ar "الصنف",
       SUM(l.qty * l.factor) "الكمية (أساسية)",
       SUM(l.line_total) "المبيعات",
       SUM(-stl.value_base) "التكلفة",
       SUM(l.line_total) - SUM(-stl.value_base) "الربح"
FROM pos_sale_lines l
JOIN pos_sales s ON s.sale_id = l.sale_id AND s.sale_type = 'SALE'
JOIN items i ON i.item_id = l.item_id
JOIN stock_trans st ON st.source_type = 'POS' AND st.source_id = s.sale_id
JOIN stock_trans_lines stl ON stl.trans_id = st.trans_id AND stl.line_no = l.line_no
WHERE (:G_USER_ROLE = 'GM' OR s.company_id = :G_COMPANY_ID)
GROUP BY i.item_code, i.name_ar
ORDER BY 4 DESC
```

**الورديات:** صفحة IR على `pos_shifts` تعرض المتوقع والمعدود والفرق لكل وردية.
